# README
This repo explores some approaches to Model Predictive Control (MPC) with agents that know the environment dynamics. It corresponds to this post: https://gdubbs100.github.io/2026/01/24/MPC.html

We explore Random Shooting, Cross Entropy Method, Model Predictive Path Integral and Gradient Based MPC.
We use a custom built (simple) physics sim with a CartPole style environment.
